# Batch Attribute Alignment

Reduce Real/Fake attribute mismatch **by selecting batch membership**. The model,
loss, image data and optimizer are unchanged. This repository contains a
detector-independent NumPy implementation and a PyTorch batch-sampler adapter.

## Install

```bash
git clone https://github.com/nuozimiaowu/batch-attribute-alignment.git
cd batch-attribute-alignment
pip install -e .
python examples/synthetic_demo.py
```

Python 3.10+ is required. The core depends only on NumPy. Install
`pip install -e '.[dev]'` to run `pytest` and `python -m build`.

## Use in training

Prepare a matrix of **source-training attributes**, binary labels (0 Real,
1 Fake), and the baseline sampler's epoch plan. A plan is a 2-D integer array
of dataset row indices; -1 denotes padding. Repeated occurrences are supported.

```python
from batchalign import BatchAligner, PlanBatchSampler, balanced_plan

# x: [N, A] attributes; labels: [N]. Use the same row ordering everywhere.
reference = balanced_plan(labels, batch_size=32, seed=0)
aligner = BatchAligner().fit(x, labels, reference, attribute_names=names)

# In each epoch, first obtain exactly the plan the control would have used.
baseline = balanced_plan(labels, batch_size=32, seed=epoch)
result = aligner.align(baseline, epoch=epoch)
print(result.summary())
loader = DataLoader(dataset, batch_sampler=PlanBatchSampler(result.aligned_plan))
```

`DataLoader` is imported from `torch.utils.data`. Replace `balanced_plan` with
your existing sampler plan when preserving an existing training protocol.
The example balanced sampler uses each selected image once and is limited by
the smaller class; it does not silently oversample the minority class.

See [the runnable CPU demo](examples/synthetic_demo.py),
[PyTorch integration](examples/pytorch_integration.py), and
[method and protocol](docs/method.md). [中文说明](docs/README_zh.md).

## What is aligned?

For each attribute and batch, form separate normalized probability-mass
histograms for Real and Fake. Minimize their Euclidean distance, averaged
across attributes after dividing each distance by its source reference scale.
The default is **equal weight across attributes**. A single attribute is
supported by passing one column.

Representative inputs are face area / image area, normalized vertical face
position, absolute yaw, log2 image pixel area, sharpness, and black-border
fraction. These are proxies for six categories, not mandatory columns.
Users must supply their measured attributes; the package does not infer face
landmarks or pose, download images, or modify them.

The optimizer exchanges same-class image occurrences between nearby batches.
It preserves the epoch's exact occurrence multiset, every batch's class slots,
and padding. It guarantees a non-increasing **joint pool objective**, not an
improvement in every attribute, batch, or detector metric.

## Reproducibility

Freeze bins and scales using source-training data and the epoch-0 baseline
plan. Use identical initialization, epoch exposure, optimizer, augmentation,
checkpoint selection and evaluation in both arms. For stochastic transforms,
replay randomness by image ID and epoch, rather than batch position. The optional
helper in `batchalign.torch_utils` isolates per-image transform RNG from model RNG.

`result.save(directory)` writes original/aligned plans and per-batch distances;
`aligner.save(path)` freezes the fitted rules. A loaded aligner requires the
attribute matrix again. These outputs may contain dataset indices and labels:
store them privately when your dataset license requires it.

The CLI accepts a source-training CSV; run `batchalign --help`. It writes a row
mapping so index plans remain interpretable. No datasets or model checkpoints
are distributed here.

## Evidence and limitations

This is research code. Reduced attribute mismatch does not establish shortcut
causality or guarantee better cross-dataset generalization. The original
Xception experiments are single-seed observations, not statistical significance
claims. [Recorded results](results/xception.csv) include unsuccessful ablations;
the initial sharpness run is separate from the later sweep. No new training
results are generated by the synthetic examples.

`research/legacy_balanced_sampler.py` preserves the original balanced research
sampler for audit. The public API adds input validation, arbitrary class counts,
padding support, configurable weighting and serialization; it is not a complete
detector training framework. Integrate it into your existing training code.
